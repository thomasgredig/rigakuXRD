# rigakuXRD

[![CRAN status](https://www.r-pkg.org/badges/version/rigakuXRD)](https://CRAN.R-project.org/package=rigakuXRD)

<!-- badges: end -->

`rigakuXRD` imports and analyzes X-ray diffraction (XRD) and X-ray
reflectivity (XRR) data generated by Rigaku SmartLab instruments. It supports
ASC, TXT, RAS, and RASX files, with tools for visualization, peak fitting,
fringe-based film-thickness estimates, and exporting data for GenX.

## Installation

Install the released version from CRAN:

```r
install.packages("rigakuXRD")
```

Install the development version from GitHub when you need the latest changes:

```r
install.packages("pak")
pak::pkg_install("thomasgredig/rigakuXRD")
```

Then load the package:

```r
library(rigakuXRD)
```

## Import and visualize data

`xrd_import()` detects the reader from the file extension. Set `xrd = TRUE`
to preserve the lightweight `xrd` class, which provides convenient plotting
and filtering methods. Supported extensions are `.asc`, `.txt`, `.ras`, and
`.rasx`.

```r
filename <- xrd_sample_files("asc")
xrd_data <- xrd_import(filename, xrd = TRUE)

plot(xrd_data)
xrd_data_40 <- xrd_filter(xrd_data, 40, 50)
plot(xrd_data_40)
```

To work with a regular data frame instead:

```r
xrd_df <- xrd_import(filename)
plot(xrd_df$TwoTheta, xrd_df$I, log = "y",
     xlab = "2\u03b8 (degrees)", ylab = "Intensity (cps)")
```

Imported data contain `TwoTheta` ($2\theta$ in degrees), `I` (normalized
intensity), `I.meas` (measured intensity), and `loop` (measurement-loop
identifier). Use `xrd_sample_files()` to locate the package's ASC, TXT, RAS,
and RASX example files.

## Peak finding and analysis

Use `xrd_peak_estimate()` for a quick estimate of the dominant peak, then
`xrd_find_peak()` or `xrd_peak_stats()` for a Gaussian fit. The fitted
statistics can be used to calculate peak prominence and a Debye-Scherrer
crystallite-size estimate.

```r
peak_range <- xrd_filter(xrd_data, 30, 42)
estimate <- xrd_peak_estimate(peak_range)

plot(peak_range)
abline(v = estimate$th0, lwd = 2)

peak_stats <- xrd_peak_stats(peak_range, peakPos = estimate$th0)
peak_position <- xrd_find_peak(peak_range, peakPos = estimate$th0)
peak_prominence <- xrd_peak_prominence(peak_stats)
crystallite_size_A <- xrd_DebyeScherrer(peak_stats)

peak_position
peak_prominence
crystallite_size_A
```

To scan a range for multiple candidate peaks:

```r
xrd_peak_all(
  xrd_data,
  range = c(20, 80),
  delta_theta = 2,
  try_sigma = 0.1
)
```

## XRR fringes and film thickness

For reflectivity data with interference fringes, restrict the imported
spectrum to the measurement range and pass it to `xrd_fringe_analysis()`.
The result includes estimated thickness values in nanometers, detected fringe
positions, and diagnostic plots.

```r
xrr_data <- xrd_import(xrd_sample_files("ras"), xrd = TRUE)
xrr_range <- xrd_filter(xrr_data, 5, 10)
fringes <- xrd_fringe_analysis(xrr_range)

fringes$t.nm
fringes$g.peaks
fringes$g.thickness
```

For a direct estimate from two adjacent fringe positions, use
`xrd_fringe_thickness()`. Its result is in angstroms:

```r
xrd_fringe_thickness(66.22698, 66.32140) / 10
```

## Export data for GenX

`export2genx()` normalizes and writes a two-column, tab-separated file for
GenX. The function returns the path to the created file.

```r
genx_file <- export2genx(
  xrr_data,
  exportPath = tempdir(),
  minTheta = 0,
  maxTheta = 4,
  GenX_filename = "xrr_data_genx.txt"
)
genx_file
```
